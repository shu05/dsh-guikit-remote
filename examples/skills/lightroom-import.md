# Lightroom Classic: импорт папки в каталог

## Быстрый путь
1. **Библиотека**: `gui_key g` (при необходимости сначала клик в окно + Esc). Проверка — `gui_wait { mode: window, title: "Библиотека" }` (заголовок главного окна меняется).
2. **Импорт...**: клик `(L+240, T+1300)` от origin главного окна (низ левой панели, под деревом папок).
3. **Окно импорта**: отдельное окно с заголовком **ровно «Lightroom»** (не «Импорт»!) — `gui_window list title:"Lightroom"` даёт два окна, импортное — с title=="Lightroom" и другим handle. Origin у него свой (например (40,60), 2633×1681). UI собственное — **UIA нет, только визуальный путь**.
4. **Дерево источника (слева)**: списки дисков; клик по строке = выбор, клик по треугольнику (L+92 от окна) = свернуть/развернуть. Строка ~52 px физ.
   - **Ленивая загрузка**: у развернутого диска видна только ранее открытая ветка. Чтобы увидеть ВСЕ папки диска — **свернуть диск и развернуть заново** (один клик по треугольнику, скрин, второй клик, скрин).
   - Дальше скролль `gui_scroll` по дереву (работает, когда дерево стало прокручиваемым), разверни нужную ветку, клик по строке целевой папки.
5. **Подожди ~30 с** (прогрузка превью; строка снизу «N фото/M МБ», все галочки «Все фотографии» проставлены) → клик **«Импорт»** — низ окна справа, ≈ origin+(2206, 1586) для окна 2633×1681.
6. **Окно закрывается СРАЗУ** после нажатия «Импорт» — ждать не нужно, сразу Библиотека. Проверка: `gui_window list` — импортного окна нет.
7. **Выбрать папку в дереве Папки**: клик в поле «Фильтровать папки» `(L+250, T+437)` → напечатай имя (Ctrl+A не нужен, если поле пусто) → дерево покажет совпадения **с предками** → скрин области `(L, T, ~700×1400)`, замерь строку, клик по ней (появится светлая полоса выделения) → снять фильтр: клик в поле, Ctrl+A, Delete.

## Pitfalls
- Заголовок окна импорта — «Lightroom»; поиск по «Импорт» ничего не даёт.
- Дерево источника ленивое: неполный список детей = свернуть/развернуть диск, не скроллить в надежде.
- Скролл-колесо над деревом молчит, пока дерево не стало прокручиваемым (вместит все строки).
- После клика по папке НЕ жми Ctrl+A — выделит все фото в сетке; для выбора папки это лишнее.
- Координаты импортного окна — от ЕГО origin (40,60), не от главного (28,8).
- Тост «AI is controlling this computer»: пользователь забирает управление комбинацией **Ctrl+Alt+Shift+Backspace** (fast takeover); если гейт залип в USER_CONTROL навсегда — рестартируй сервер задачи `windows-mcp-server` на машине (schtasks /end + /run), это сбрасывает fast_takeover.
