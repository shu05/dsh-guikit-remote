# Lightroom Classic: модуль «Библиотека» + выбор папки по пути (удалённая машина)

## Быстрый путь (проверено, ~5-10 с на папку)
1. **`gui_lr_folder { query }`** — один вызов: находит окно Lightroom, активирует, `Esc`+`G` (модуль Library — горячая клавиша, кликать «Библиотека» не надо), прокручивает левую панель наверх, кликает поле **«Фильтровать папки»** (T+437), `Ctrl+A`, печатает query, возвращает PNG панели 1:1 + модуль из заголовка окна («… - Библиотека»).
2. **Query = уникальное имя листа** («2026_10_16», не «cr3» — cr3 есть у каждой школы). Фильтр показывает совпадения ВМЕСТЕ с цепочками предков — нужный лист виден сразу.
3. **Выбор совпадения**: по PNG измерить строку пикселями (PIL: подсветка выбранной строки ~178 luminance; текст на тёмном r,g,b>150), физический клик = origin снимка + preview_px × scale. Кликовать `gui_click` по середине текстовой полосы строки.
4. **Если лист скрыт фильтром** (cr3 не совпадает с «2026_10_16»): снять фильтр — клик по полю (T+437), `Ctrl+A`, `Delete`; дерево разворачивается с сохранённым состоянием; доскроллить до предка (`gui_scroll` down 3-5), измерить строку листа, кликнуть.
5. **Проверка**: полоса подсветки на целевой строке (не на глаз!) + статус-бар «N фото». Счётчики родителя и листа могут совпадать — различай только по подсветке.

## Ловушки (все наступили)
- **Type-ahead в дереве папок НЕ работает**; стрелки/буквы без фокуса дерева уходят в сетку фото: Right = следующее фото, Ctrl+A = выделить все фото («стрелки делают абсолютно другое»). Никакой навигации клавишами по дереву.
- **Клик по шапке «Папки» = переключатель сворачивания**: по свернутой — разворачивает (источник = папки), по развернутой — сворачивает и источник прыгает на «Коллекции». Не кликай шапку лишний раз; если PNG показал дерево коллекций — один клик по шапке (~T+380) и повтор вызова.
- Поле фильтра лежит на **T+437 только при прокрутке наверх** и развернутой «Папки»; инструмент сам скроллит наверх перед кликом.
- **UIA-дерева у Lightroom нет** (gui_uia → not-exposed) — только визуальный путь.
- **Никогда не оценивай мелкие цели на глаз** (треугольники ~14 px, строки ~37 px): vision-модель систематически врёт на 20-45 px. Метод: PIL по сохранённому PNG, физический клик = origin + px×scale.
- Пользователь за машиной → гейт USER_CONTROL задерживает действия на ~10 с; не спамь повторами.
- Пунктирный треугольник у папки = подпапки есть на диске, но не в каталоге: правый клик по родителю → «Синхронизировать папку».
- Горячие клавиши модулей: G = Библиотека, D = Обработка. Перед G жми Esc (снимает фокус с текстовых полей, иначе G печатается в поле).

## Проверка результата
Скриншот области дерева → PIL-поиск светлой полосы (~178) в окне строк цели → полоса на целевой строке = выбор подтверждён.

## Закрытие Lightroom (проверено)
- Завершать работу закрытием LR: клик в любое место главного окна (фокус на LR) → `gui_key ctrl+q` → Lightroom закрывается **мгновенно, без диалога подтверждения**.
- Подтверждение: `gui_wait { mode: window, title: "Lightroom", timeoutMs: 15000 }` → `met:false` и `gui_window list title:"Lightroom"` пусто.
- После Ctrl+Q handle главного окна протухает — следующий запуск LR даёт новый pid/handle/геометрию, калибровки координат сбрасывать.
