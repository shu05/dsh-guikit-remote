# Lightroom Classic: выделить всё + экспорт (быстрый путь, ~10 с, 0 полноразмерных скриншотов)

Диалог «Экспорт файлов» и «Выбрать папку» — **нативные Win32: UIA-дерево полное** (в отличие от главного окна LR). Все координаты — из `gui_uia`, скриншоты почти не нужны.

## Шаг 1 — выделить все фото (фокус с дерева на сетку!)
1. `gui_click` по любой миниатюре сетки: `(L+150, T+1450)` для окна с origin (L,T) — сетка прибита вниз, при сотнях фото ячейка точно есть.
2. `gui_key ctrl+a`.
3. Проверка (опционально, один узкий снимок): region `[L+400, T+1370, L+1400, T+1400]` → «Выделено N». Без снимка — доверять, если перед этим выбиралась папка с фото.
- ⚠ Ctrl+A при фокусе дерева может не сработать по фото — поэтому клик в сетку обязателен.

## Шаг 2 — открыть диалог
- `gui_key ctrl+shift+e` → `gui_wait { mode: window, title: "Экспорт" }` (не скриншот!).
- `gui_window { action: list, title: "Экспорт" }` → handle. ⚠ `gui_click window=` по кириллическому подстрочному заголовку не находит окно — передавай **handle числом**.

## Шаг 3 — ОДИН вызов `gui_uia { action: tree, handle }` закрывает всю сверку
По names из дерева читается всё сразу: «Жесткий диск», «Определенная папка», путь папки (name=путь), «Нижний регистр», «JPEG», «90», «sRGB IEC61966-2.1», координаты кнопок «Выбрать...» и «Экспорт» (прямоугольник → центр).
- Чекбоксы («Поместить в подпапку», «Добавить в этот каталог», «Переимен. в») — **state в UIA не виден** (голые Pane). Либо довериться персистентности (LR помнит настройки экспорта между прогонами), либо один крошечный снимок `[labelX-7, y1-8, labelX+55, y3+8]` на все три сразу.

## Шаг 4 — смена папки (если путь не тот)
1. Клик «Выбрать...» (центр из UIA).
2. `gui_window list title:"Выбрать папку"` → handle.
3. `gui_uia find name:"Папка"` → label-Pane «Папка:» (ValuePattern у него НЕТ, self не кликать). Поле ввода — широкое справа от label: клик в `(labelX+450, labelY)`.
4. `gui_key ctrl+a` (выделить старое значение) → `gui_type` полный путь.
5. **Поле пути в UIA не читается** (Edit-элементы дерева — это колонки списка). Подтверждение — один узкий снимок нижней строки диалога пикера; пересчёт image px → screen: `origin + img_px × scale`. Кнопка «Выбор папки» — примерно на `(dlgX + 0.865*dlgW, labelY+48)`.
6. После закрытия пикера — `gui_uia find name:"<имя папки>"` в диалоге экспорта: путь в поле «Папка:» подтверждается.
- ⚠ **Подпапка «Поместить в подпапку:» persist из прошлого экспорта** (например `jpg`) и подмешивает лишний уровень. Если целевая папка нужна «как есть» — кликнуть в поле подпапки, `ctrl+a`, `delete`; проверить `gui_uia find name:"jpg"` — value-Pane подпапки должен исчезнуть.

## Шаг 5 — пуск
- `gui_click` «Экспорт» (центр rect из UIA) → диалог закрывается, прогресс в левом верхнем углу главного окна.

## Pitfalls
- Не скриншотить диалог целиком — UIA даёт то же быстрее и точнее.
- «Качество 90 / JPEG / sRGB» обычно уже стоят из прошлого экспорта — сверять одним tree-вызовом, не трогать.
- После «Выбор папки» фокус возвращается к диалогу экспорта — следующий клик по handle экспорта.
